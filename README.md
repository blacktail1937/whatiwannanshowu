# What I wanna show U

把物品分享到聊天栏，格式为`[物品icon][物品名]`，点击物品名可以打开JEI配方（如果安装了jei并且有配方页面）。

> **English**: Share items to chat with a real item-model icon (glint, tint and multi-layer models included). `G` shares
> the item in hand, or the one under the cursor in a container/JEI screen; `V` shares whatever is under the crosshair.
> Clicking a link opens the JEI recipe. Minecraft 1.21.1 / NeoForge; both client and server need the mod.

## 分享物品到聊天

| 按键         | 默认键 | 什么时候用            | 分享什么         |
|--------------|--------|-----------------------|------------------|
| 分享         | `G`    | 世界里（没开界面）    | 主手拿着的物品   |
| 分享         | `G`    | 打开容器或 JEI 界面时 | 鼠标指针下的物品 |
| 分享准星目标 | `V`    | 世界里（没开界面）    | 准星下面的东西   |

按键可以在「选项 → 控制」里改，按键分类是 **What I wanna show U**。

按 `V` 时 **准星离谁近就取谁**，被墙挡住的不算；没有东西可分享就什么都不做。

| 准星对着                       | 分享出来的东西                                                                                                                               |
|--------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|
| 方块                           | 它的物品形态，和原版**中键选取方块**一致：作物给作物、花盆带着里面的花、潜影盒带着内容物、带图案的旗帜带着图案；水、火这类拿不到的方块不分享 |
| 地上的掉落物                   | 那一堆物品的**本体**（附魔、名字、数量都在）                                                                                                 |
| 物品展示框                     | 框里挂着的物品                                                                                                                               |
| 生物 / 船 / 矿车 / 盔甲架 / 画 | 刷怪蛋 / 本体 / 本体 / 本体 / 画                                                                                                             |

能取到的距离，和 WAILA、Jade 那类提示 mod 显示提示的范围一致（原版"方块交互距离"，默认 4.5 格）。

## 聊天栏里的链接

分享成功后聊天栏会出现这样一条：

```
<玩家名> [物品icon] [物品名]
```

- **图标**：画的是真正的物品模型 —— 附魔有光效，草方块和树叶的染色、药水和皮革甲的多图层也都正确；图标和玩家名、物品名之间各留一个空格；
- **颜色**：文字按物品稀有度着色；
- **悬停**：显示原版物品说明（附魔、耐久、数量、自定义数据都在）；
- **点击**：打开该物品的 JEI 配方；

## 安装

|          | 要求                                                                     |
|----------|--------------------------------------------------------------------------|
| 游戏版本 | Minecraft **1.21.1** + NeoForge **21.1** 或更高                          |
| 客户端   | **必须安装**                                                             |
| 服务端   | **也要安装** —— 分享需要经服务端转发给其他玩家。单人游戏自带，不用额外装 |
| JEI      | 可选。装了才能点击链接打开配方                                           |

## 配置

`config/whatiwannashowu-common.toml`

| 配置项              | 默认   | 范围      | 说明                                                                                                                                                                     |
|---------------------|--------|-----------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `maxCompressedSize` | `128`  | 128 ~ 512 | 分享数据的体积上限（KB）。超过就只发物品 ID 和数量，不再带附魔、名字等附加数据                                                                                           |
| `shareCooldown`     | `500`  | 0 ~ 60000 | 两次分享之间的最短间隔（毫秒），`0` = 不限制；冷却中会在动作栏提示剩余秒数                                                                                               |
| `renderItemsInChat` | `true` | 开 / 关   | 关掉后新分享的物品不再画图标，只显示成普通的 `[物品名]` 链接（玩家名和物品名之间仍留一个空格；悬停说明、点击查配方照常）。**已经在聊天栏里的消息不受影响**，图标照旧显示 |

目前只能在客户端生效，服务端未做限制。

## 注意事项

- 分享的冷却和体积上限只在客户端生效。
- 重新登录后，旧聊天记录里的链接点了没有反应（链接指向本机缓存的物品数据）。
- 一条消息只显示一个图标。
- `V` 只在没有打开界面时生效。
- 准星下没有可分享的东西时不会有任何提示。
- 对方物品数据缺失时（比如他装了你没有的 mod），图标会显示成一个屏障方块，不会在聊天栏里留个空洞。

## 已知兼容性问题

由于修改了聊天栏的部分渲染，和其他也做了此改动的mod一起使用可能会出现奇怪的渲染问题。
