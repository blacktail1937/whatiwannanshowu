# What I wanna show U

把物品分享到聊天栏，聊天栏里直接画出那个物品的模型（附魔光效、染色、多图层都是对的），点击链接就能打开它的 JEI 配方。

> **English**: Share items to chat with a real item-model icon (glint, tint and multi-layer models included). `G` shares the item in hand, or the one under the cursor in a container/JEI screen; `V` shares whatever is under the crosshair. Clicking a link opens the JEI recipe. Minecraft 1.20.1 / Forge; both client and server need the mod.

## 分享物品到聊天

| 按键 | 默认键 | 什么时候用 | 分享什么 |
| --- | --- | --- | --- |
| 分享 | `G` | 世界里（没开界面） | 主手拿着的物品 |
| 分享 | `G` | 打开容器或 JEI 界面时 | 鼠标指针下的物品 |
| 分享准星目标 | `V` | 世界里（没开界面） | 准星下面的东西 |

按键可以在「选项 → 控制」里改。

按 `V` 时**准星离谁近就取谁**，被墙挡住的不算；没有东西可分享就什么都不做。

| 准星对着 | 分享出来的东西 |
| --- | --- |
| 方块 | 它的物品形态，和原版**中键选取方块**一致：作物给作物、花盆带着里面的花、潜影盒带着内容物、带图案的旗帜带着图案；水、火这类拿不到的方块不分享 |
| 地上的掉落物 | 那一堆物品的**本体**（附魔、名字、数量都在） |
| 物品展示框 | 框里挂着的物品 |
| 生物 / 船 / 矿车 / 盔甲架 / 画 | 刷怪蛋 / 本体 / 本体 / 本体 / 画 |

能取到的距离，和 WAILA、Jade 那类提示 mod 显示提示的范围一致。

## 聊天栏里的链接

分享成功后聊天栏会出现这样一条：

```
<玩家名>[<物品模型> 物品名]
```

- **图标**：画的是真正的物品模型 —— 附魔有光效，草方块和树叶的染色、药水和皮革甲的多图层也都正确；
- **颜色**：文字按物品稀有度着色；
- **悬停**：显示原版物品说明（附魔、耐久、数量、自定义数据都在）；
- **点击**：打开该物品的 JEI 配方；
- 消息淡出时，图标和文字一起淡出。

这条消息只显示给装了本 mod 的玩家，不会进入服务器聊天记录。

## 安装

| | 要求 |
| --- | --- |
| 游戏版本 | Minecraft **1.20.1** + Forge **47.4.10** 或更高 |
| 客户端 | **必须安装** |
| 服务端 | **也要安装** —— 分享需要经服务端转发给其他玩家。单人游戏自带，不用额外装 |
| JEI | 可选。装了才能点击链接打开配方 |

## 配置

`config/whatiwannashowu-common.toml`

| 配置项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| `maxCompressedSize` | `128` | 1 ~ 512 | 分享数据的体积上限（KB）。超过就只发物品 ID 和数量，不再带附魔、名字等附加数据 |
| `shareCooldown` | `1000` | 0 ~ 60000 | 两次分享之间的最短间隔（毫秒），`0` = 不限制 |

## 注意事项

- 在专用服务器上，点击链接**可能**打不开 JEI（该功能需要服务端支持；单人和局域网正常）。
- 分享的冷却和体积上限只在客户端生效。
- 重新登录后，旧聊天记录里的链接点了没有反应（链接指向本机缓存的物品数据）。
- 一条消息只显示一个图标。
- 如果同时装了其他改动聊天栏的 mod（例如 Quark 的物品分享），可能冲突；冲突时关掉其中一个。
- `V` 只在没有打开界面时生效。
- 准星下没有可分享的东西时不会有任何提示。
